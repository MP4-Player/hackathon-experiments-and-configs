## 📱 ТЕСТИРОВАНИЕ НА МОБИЛЬНЫХ

### В Chrome DevTools (рекомендуется для начала):
1. Откройте приложение в Chrome
2. Нажмите **F12** (откроется DevTools)
3. Нажмите **Ctrl+Shift+M** (Device Mode)
4. Выберите устройство: iPhone 12, Samsung Galaxy, iPad и т.д.
5. Попробуйте drag & drop!

### На реальном мобильном устройстве:
1. Узнайте IP вашего компьютера:
   - Windows: `ipconfig`
   - Mac/Linux: `ifconfig`
2. На телефоне откройте браузер
3. Введите: `http://[ваш-IP]:5173`
4. Например: `http://192.168.1.100:5173`

## 🛠️ ЕСЛИ ВОЗНИКЛИ ПРОБЛЕМЫ

### Проблема: Сервер не запускается
**Решение:**
```bash
# Переустановите зависимости
rm -rf node_modules package-lock.json
npm install

# Запустите снова
npm run dev
```

### Проблема: Права доступа (Permission denied)
**Решение:**
```bash
# Дайте права на выполнение
chmod +x node_modules/.bin/*

# Или используйте npx
npx vite
```

### Проблема: Порт уже занят
**Решение:**
```bash
# Убейте процесс на порту 5173
lsof -ti:5173 | xargs kill -9

# Или укажите другой порт
npx vite --port 3000
```

### Проблема: TypeScript ошибки
**Решение:**
```bash
# Проверьте типы
npx tsc --noEmit

# Если есть ошибки - проверьте файлы типов
```
