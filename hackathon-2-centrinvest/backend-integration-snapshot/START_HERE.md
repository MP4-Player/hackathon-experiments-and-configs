## 🎬 Как использовать

### Вкладка "Типы встреч"

1. **Создать встречу:**
   - Нажмите "+ Создать встречу"
   - Заполните форму
   - Нажмите "Сохранить"

2. **Перетащить встречу в тип:**
   - Зажмите карточку встречи
   - Перетащите в нужный тип (например, "Встречи с клиентами")
   - Отпустите

3. **Редактировать встречу:**
   - Нажмите иконку карандаша на карточке
   - Измените данные
   - Нажмите "Сохранить"

4. **Удалить встречу:**
   - Нажмите иконку корзины
   - Нажмите еще раз для подтверждения (в течение 3 секунд)

### Вкладка "Расписание"

1. **Изменить порядок встреч:**
   - Зажмите карточку встречи
   - Перетащите на новую позицию
   - Отпустите

2. **Оптимизировать маршрут:**
   - Нажмите "Оптимизировать маршрут"
   - Система автоматически упорядочит встречи

3. **Сохранить изменения:**
   - Нажмите "Сохранить"

## 🔌 API Интеграция

### Готовые эндпоинты:

1. **Оптимизация маршрута**
   ```
   POST /api/meetings/optimize-route
   ```

2. **Точки на карте**
   ```
   POST /api/meetings/schedule-map-locations
   ```

3. **Обновление типа встречи**
   ```
   PATCH /api/meetings/:id/type
   ```

4. **Обновление порядка**
   ```
   PUT /api/meetings/schedule-order
   ```

Подробнее в [API_ENDPOINTS.md](./API_ENDPOINTS.md)
