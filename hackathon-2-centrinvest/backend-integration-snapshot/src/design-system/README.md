# Дизайн-система ЦентрИнвест

## 🎨 Цветовая палитра

### Основные цвета
- **Primary (Зеленый)**: `#39aa34` - основной цвет бренда
- **Secondary (Кремовый)**: `#f6f7f1` - нейтральный фон
- **Accent (Ярко-зеленый)**: `#14c94d` - акцентный цвет
- **Background**: `#ffffff` - белый фон
- **Surface**: `#f6f7f1` - поверхность карточек

### Градиенты
- **Hero Gradient**: `linear-gradient(135deg, #FFF001 0%, #3CC730 100%)`
- **Card Gradient**: `linear-gradient(145deg, #f6f7f1 0%, #f0f0e6 100%)`

## 🎭 Анимации

### Основные анимации
- `animate-float` - плавающее движение (6s)
- `animate-pulse-slow` - медленное пульсирование (4s)
- `animate-bounce-slow` - медленное подпрыгивание (3s)
- `animate-spin-slow` - медленное вращение (8s)
- `animate-star-twinkle` - мерцание звезд (2s)
- `animate-gradient` - анимированный градиент (15s)

### Эффекты появления
- `animate-slide-in` - появление слева
- `animate-fade-in` - плавное появление
- `animate-scale-in` - масштабирование

## 🧩 Компоненты

### Кнопки
- `.btn-primary` - основная кнопка с градиентом
- `.btn-secondary` - вторичная кнопка
- `.btn-accent` - акцентная кнопка

### Карточки
- `.card` - базовая карточка с градиентом
- `.card-hover` - карточка с эффектом наведения
- `.glass-effect` - стеклянный эффект

### Текст
- `.text-gradient` - градиентный текст
- `.hero-title` - заголовок героя
- `.floating-element` - плавающий элемент

## 🎪 Специальные эффекты

### Анимированный фон
- Градиент от #FFF001 до #3CC730
- Символы % разного размера
- Реакция на движение мыши
- Звездное небо эффект

### Калейдоскоп
- Автоматическая смена изображений
- Ручная навигация
- Эффекты отражения
- Плавные переходы

## 📱 Адаптивность

### Брейкпоинты
- Mobile: < 768px
- Tablet: 768px - 1024px
- Desktop: > 1024px

### Типографика
- **Display**: Poppins (заголовки)
- **Body**: Inter (основной текст)
- **Sizes**: 12px - 80px

## 🎯 Принципы дизайна

1. **Современность** - актуальные тренды и технологии
2. **Динамика** - анимации и интерактивность
3. **Доступность** - контрастность и читаемость
4. **Производительность** - оптимизированные анимации
5. **Консистентность** - единый стиль во всем приложении
