# Изображения для проекта

## Папка для загрузки изображений
Все изображения должны быть загружены в папку: `src/assets/images/`

## Необходимые изображения

### 1. Аналитика встреч (analytics-meetings.jpg)
- **Размер**: 400x300px
- **Описание**: График или диаграмма, показывающая статистику встреч
- **Стиль**: Современный, минималистичный дизайн с зелеными акцентами
- **Использование**: Калейдоскоп дашборда, карточка функций

### 2. Управление клиентами (client-management.jpg)
- **Размер**: 400x300px
- **Описание**: Интерфейс управления клиентской базой или CRM система
- **Стиль**: Профессиональный дизайн с синими акцентами
- **Использование**: Калейдоскоп дашборда, карточка функций

### 3. Планировщик задач (task-planner.jpg)
- **Размер**: 400x300px
- **Описание**: Календарь или список задач с чекбоксами
- **Стиль**: Чистый, организованный дизайн с фиолетовыми акцентами
- **Использование**: Калейдоскоп дашборда, карточка функций

### 4. Карта маршрутов (route-map.jpg)
- **Размер**: 400x300px
- **Описание**: Карта с маршрутами или GPS навигация
- **Стиль**: Современный дизайн карты с оранжевыми акцентами
- **Использование**: Калейдоскоп дашборда, карточка функций

### 5. Отчеты и аналитика (reports-analytics.jpg)
- **Размер**: 400x300px
- **Описание**: Дашборд с графиками и отчетами
- **Стиль**: Профессиональный дизайн с зелеными акцентами
- **Использование**: Калейдоскоп дашборда, карточка функций

## Текущее состояние
Пока изображения не загружены, используются символы "%" как заглушки.

## Форматы изображений
- **Рекомендуемый формат**: JPG или PNG
- **Качество**: Высокое разрешение для четкости на всех устройствах
- **Оптимизация**: Сжатие для быстрой загрузки

## Замена заглушек
После загрузки изображений замените символы "%" в следующих файлах:
- `src/components/ui/Kaleidoscope.tsx` (строка 95)
- `src/pages/LandingPage.tsx` (строки 305, 313, 321, 329, 337)
