# Быстрый старт

## 🚀 Как запустить приложение

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```

Приложение будет доступно по адресу: **http://localhost:3000**

## 🔑 Данные для входа

### Админ-пользователь (всегда доступен):
- **Email:** `admin@example.com`
- **Пароль:** `Admin1`

### Регистрация нового пользователя:
1. Перейдите на страницу регистрации
2. Заполните форму
3. После регистрации вы автоматически войдете в систему

## 🎨 Новый дизайн

### Современный интерфейс с анимациями:
- **Анимированный фон** с градиентом и символами %
- **Калейдоскоп дашборда** с автоматической сменой изображений
- **Плавные анимации** и эффекты наведения
- **Стеклянные эффекты** и градиенты
- **Адаптивный дизайн** для всех устройств

## 📱 Основные функции

### После входа в систему вы можете:

1. **Карта** - интерактивная карта с калейдоскопом и анимированными маркерами
2. **Встречи** - управление встречами с современным дизайном
3. **Клиенты** - база клиентов с приоритизацией и анимациями
4. **Задания** - создание и отслеживание задач с динамическими эффектами
5. **Статистика** - аналитика и отчеты с визуализацией

## 🛠 Технические детали

- **Фронтенд:** React 18 + TypeScript + Tailwind CSS
- **Сборка:** Vite
- **Состояние:** React Query
- **Маршрутизация:** React Router
- **Тестирование:** Jest + React Testing Library

## 📁 Структура проекта

```
src/
├── components/     # Переиспользуемые компоненты
├── hooks/         # Пользовательские хуки
├── pages/         # Страницы приложения
├── services/      # API сервисы (мок-реализация)
├── types/         # TypeScript типы
└── utils/         # Утилиты
```

## 🔧 Команды разработки

```bash
# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Предварительный просмотр сборки
npm run preview

# Запуск тестов
npm test

# Проверка линтинга
npm run lint
```

## 📝 Примечания

- Все данные хранятся в localStorage (мок-реализация)
- Админ-пользователь всегда доступен для входа
- Приложение готово к интеграции с реальным API
- Все эндпоинты документированы в `api-examples.md`
