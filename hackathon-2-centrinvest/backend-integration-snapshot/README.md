# ЦентрИнвест - Управление встречами

Веб-приложение для управления сотрудниками, клиентами, задачами и отчетностью с интуитивно понятным интерфейсом.

## Технологический стек

- **React 18** с TypeScript
- **Vite** - быстрый сборщик
- **React Router** - маршрутизация
- **React Query** - управление состоянием сервера
- **Tailwind CSS** - стилизация
- **React Hook Form** - формы
- **Axios** - HTTP клиент
- **Jest + React Testing Library** - тестирование

## Возможности

### Аутентификация и авторизация
- Регистрация и авторизация пользователей
- Защита маршрутов
- Сохранение токена авторизации
- Автоматическое перенаправление

### Управление данными
- **Встречи**: создание, редактирование, удаление встреч
- **Клиенты**: управление базой клиентов с приоритизацией
- **Задачи**: создание и отслеживание задач
- **Карта**: отображение местоположений на карте
- **Статистика**: детальная аналитика и отчеты

### Интерфейс
- Адаптивный дизайн для всех устройств
- Интуитивная навигация
- Глобальный поиск
- Система уведомлений
- Фильтрация и сортировка данных

## 🚀 Быстрый запуск

### Предварительные требования
- Node.js 18+
- npm или yarn

### Способ 1: Автоматический запуск (Windows)
Просто запустите файл `start.bat` - он автоматически установит зависимости и запустит приложение.

### Способ 2: Ручной запуск
```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev
```

Приложение будет доступно по адресу **http://localhost:3000**

## API Интеграция

Приложение готово к интеграции с REST API. Настройте базовый URL API в переменной окружения `VITE_API_BASE_URL`.

### Ожидаемые эндпоинты:

#### Аутентификация
- `POST /auth/login` - авторизация
- `POST /auth/register` - регистрация
- `POST /auth/logout` - выход

#### Встречи
- `GET /meetings` - список встреч
- `POST /meetings` - создание встречи
- `PUT /meetings/:id` - обновление встречи
- `DELETE /meetings/:id` - удаление встречи

#### Клиенты
- `GET /clients` - список клиентов
- `POST /clients` - создание клиента
- `PUT /clients/:id` - обновление клиента
- `DELETE /clients/:id` - удаление клиента

#### Задачи
- `GET /tasks` - список задач
- `POST /tasks` - создание задачи
- `PUT /tasks/:id` - обновление задачи
- `DELETE /tasks/:id` - удаление задачи

#### Карта
- `GET /map/locations` - местоположения
- `GET /map/search` - поиск по адресу
- `GET /map/route` - построение маршрута
