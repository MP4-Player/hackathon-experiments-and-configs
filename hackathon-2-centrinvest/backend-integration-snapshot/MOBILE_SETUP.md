# Быстрый старт - Мобильный интерфейс встреч

## Запуск приложения

### 1. Установка зависимостей (если еще не установлены)
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```

Приложение откроется по адресу: `http://localhost:5173`

### 3. Просмотр на мобильном устройстве

#### Вариант A: Chrome DevTools
1. Откройте приложение в Chrome
2. Нажмите F12 (DevTools)
3. Нажмите Ctrl+Shift+M (Device Mode)
4. Выберите устройство (iPhone 12, Samsung Galaxy, etc.)

#### Вариант B: Реальное устройство
1. Убедитесь, что ваше устройство в той же сети Wi-Fi
2. Узнайте IP адрес компьютера: `ipconfig` (Windows) или `ifconfig` (Mac/Linux)
3. На мобильном устройстве откройте: `http://[ваш-IP]:5173`

Пример: `http://192.168.1.100:5173`

## Тестирование новых функций

### Вкладка "Типы встреч"
1. Перейдите на страницу "Встречи" в меню
2. Убедитесь, что выбрана вкладка "Типы встреч"
3. Попробуйте:
   - Перетащить встречу в другой тип (drag & drop)
   - Создать новую встречу (кнопка "+ Создать встречу")
   - Редактировать встречу (иконка карандаша)
   - Удалить встречу (иконка корзины, нужно нажать дважды)
   - Сохранить изменения (кнопка "Сохранить")

### Вкладка "Расписание"
1. Переключитесь на вкладку "Расписание"
2. Попробуйте:
   - Изменить порядок встреч (drag & drop)
   - Нажать "Оптимизировать маршрут"
   - Посмотреть расчетное время в пути
   - Сохранить изменения

## Известные ограничения

2. **API**: Используются mock данные. Для production нужно подключить реальный backend
