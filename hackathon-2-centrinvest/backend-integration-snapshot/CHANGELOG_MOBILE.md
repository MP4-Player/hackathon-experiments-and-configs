### 🚀 API Endpoints

#### Новые эндпоинты:
1. `POST /api/meetings/optimize-route` - Оптимизация маршрута
2. `POST /api/meetings/schedule-map-locations` - Точки на карте
3. `PATCH /api/meetings/:id/type` - Обновление типа встречи
4. `PUT /api/meetings/schedule-order` - Обновление порядка
