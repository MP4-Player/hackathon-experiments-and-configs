# Руководство по новому интерфейсу встреч (Мобильная версия)

## Обзор

Интерфейс встреч был полностью переработан для мобильных устройств с двумя основными вкладками:
1. **Типы встреч** - управление встречами с drag-and-drop функционалом
2. **Расписание** - просмотр расписания с картой и оптимизацией маршрута

## Вкладка "Типы встреч"

### Функционал:
- **Список встреч**: Отображение всех встреч в виде карточек
- **Drag & Drop**: Перетаскивание встреч в категории типов
- **7 типов встреч**:
  - Рабочие совещания (синий)
  - Встречи с партнерами (фиолетовый)
  - Встречи с клиентами (зеленый)
  - Брифинг (оранжевый)
  - Презентация продукта (розовый)
  - Бизнес ланч (желтый)
  - Иное (серый)

### Карточка встречи:
- Название встречи
- С кем встреча
- Место
- VIP/Стандарт статус
- Кнопки редактирования (карандаш) и удаления (корзина)

### Удаление встречи:
- Первое нажатие на корзину активирует режим подтверждения (карточка мигает красным)
- Повторное нажатие в течение 3 секунд подтверждает удаление
- Автоматическая отмена через 3 секунды

### Управление:
- **Кнопка "Сохранить"**: Сохраняет изменения в типах встреч
- **Кнопка "Создать встречу"**: Открывает форму для новой встречи

## Вкладка "Расписание"

### Структура:
Экран разделен на две части:

#### Верхняя часть - Расписание:
- Список встреч в порядке выполнения
- Каждая карточка показывает:
  - Порядковый номер
  - Название встречи
  - Тип встречи
  - Клиент и VIP статус
  - Время начала и окончания
  - Место
  - Примерное время в пути (если доступно)
- **Drag & Drop**: Можно менять порядок встреч перетаскиванием

#### Нижняя часть - Карта:
- Визуализация встреч на карте
- Маршрут между встречами
- API эндпоинт для интеграции с картами (готов к подключению)

### Управление:
- **Кнопка "Сохранить"**: Сохраняет порядок встреч в расписании
- **Кнопка "Оптимизировать маршрут"**: Автоматически оптимизирует порядок встреч для минимизации времени в пути

## Форма создания/редактирования встречи

### Поля формы:
- **Название встречи** * (обязательное)
- **Описание**
- **С кем встреча** * (обязательное)
- **Тип встречи** (выбор из 7 типов)
- **Начало** * (дата и время)
- **Окончание** * (дата и время)
- **Место встречи** * (обязательное)
- **Адрес** * (обязательное)
- **Приоритет** * (Стандарт / VIP)

### Кнопки:
- **Отмена**: Закрывает форму без сохранения
- **Сохранить**: Сохраняет встречу

## API Endpoints

### 1. Оптимизация маршрута
```
POST /api/meetings/optimize-route
```
**Параметры:**
- `meetingIds`: массив ID встреч
- `startLocation` (опционально): начальная точка

**Возвращает:**
- Оптимизированное расписание
- Общее расстояние
- Общее время в пути
- Общая продолжительность

### 2. Получение точек на карте
```
POST /api/meetings/schedule-map-locations
```
**Параметры:**
- `scheduleItems`: массив элементов расписания

**Возвращает:**
- Координаты для отображения на карте

### 3. Обновление типа встречи
```
PATCH /api/meetings/:id/type
```
**Параметры:**
- `meetingType`: новый тип встречи

### 4. Обновление порядка встреч
```
PUT /api/meetings/schedule-order
```
**Параметры:**
- `scheduleItems`: массив с обновленным порядком

Подробнее см. [API_ENDPOINTS.md](./API_ENDPOINTS.md)

## Интеграция с картами

Для полноценной работы карты необходимо подключить один из сервисов:
- **Google Maps API** (рекомендуется)
- **Yandex Maps API** (для России)
- **OpenStreetMap + OSRM** (бесплатная альтернатива)

### Пример интеграции с Google Maps:
```typescript
// В компоненте ScheduleTab.tsx
import { GoogleMap, Marker, DirectionsRenderer } from '@react-google-maps/api'

// Инициализация карты

  width: '100%',
  height: '100%'
}

const center = {
  lat: 55.7558,
  lng: 37.6176
}
```

## TypeScript типы

### Основные типы:
```typescript
// Тип встречи
type MeetingType =
  | 'work_meeting'
  | 'partner_meeting'
  | 'client_meeting'
  | 'briefing'
  | 'product_presentation'
  | 'business_lunch'
  | 'other'

// Встреча с типом
interface MeetingWithType extends Meeting {
  meetingType?: MeetingType
  order?: number
}

// Элемент расписания
interface ScheduleItem {
  id: string
  meetingId: string
  meeting: MeetingWithType
  order: number
  estimatedTravelTime?: number
  distance?: number
}
```
