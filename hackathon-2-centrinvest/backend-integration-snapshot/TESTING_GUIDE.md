# Инструкции по тестированию интеграции

## Подготовка к тестированию

### 1. Настройка базы данных

Выполните SQL скрипт для создания таблиц:
```bash
psql -h <DB_HOST> -U api_user -d meeting_db -f database_schema.sql
```

### 2. Запуск backend

```bash
# Установите зависимости
pip install -r requirements.txt

# Запустите сервер
python main.py
```

Backend будет доступен по адресу: http://localhost:8000

### 3. Запуск frontend

```bash
# Установите зависимости
npm install

# Создайте .env файл
cp .env.example .env

# Запустите frontend
npm run dev
```

Frontend будет доступен по адресу: http://localhost:5173

## Тестирование API

### 1. Аутентификация

**Регистрация пользователя:**
```bash
curl -X POST "http://localhost:8000/auth/register" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "test@example.com",
    "password": "password123",
    "firstName": "Test",
    "lastName": "User"
  }'
```

**Вход в систему:**
```bash
curl -X POST "http://localhost:8000/auth/login" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "test@example.com",
    "password": "password123"
  }'
```

### 2. Тестирование клиентов

**Создание клиента:**
```bash
curl -X POST "http://localhost:8000/clients" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "firstName": "Иван",
    "lastName": "Петров",
    "email": "ivan@example.com",
    "phone": "+7 (999) 123-45-67",
    "company": "ООО Ромашка",
    "position": "Директор",
    "address": "ул. Ленина, 1, Москва",
    "priority": "vip"
  }'
```

**Получение списка клиентов:**
```bash
curl -X GET "http://localhost:8000/clients" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

## Возможные проблемы и решения

### 1. Ошибки подключения к базе данных

**Проблема:** `connection to server failed`
**Решение:** 
- Проверьте настройки подключения в `main.py`
- Убедитесь, что база данных доступна
- Проверьте SSL настройки

### 2. CORS ошибки

**Проблема:** `CORS policy` ошибки в браузере
**Решение:**
- Убедитесь, что frontend URL добавлен в CORS настройки в `main.py`
- Проверьте, что backend запущен на правильном порту

### 3. Ошибки аутентификации

**Проблема:** `401 Unauthorized`
**Решение:**
- Проверьте, что токен передается в заголовках
- Убедитесь, что токен не истек
- Проверьте формат токена

### 4. Ошибки валидации

**Проблема:** `422 Unprocessable Entity`
**Решение:**
- Проверьте формат данных в запросе
- Убедитесь, что все обязательные поля заполнены
- Проверьте типы данных
